# 📏 Tailor Measurement App

This Streamlit app estimates basic body measurements from a single front-facing photo.
Upload your picture and enter your height to get approximate chest, waist, sleeve and inseam dimensions.

[![Open in Streamlit](https://static.streamlit.io/badges/streamlit_badge_black_white.svg)](https://blank-app-template.streamlit.app/)

## How to run locally

1. Install the requirements

   ```bash
   pip install -r requirements.txt
   ```

2. Run the app

   ```bash
   streamlit run streamlit_app.py
   ```
